# Атлас - веб-приложение турагентства

Учебный проект. Сайт турагентства, где можно подобрать тур по параметрам, посмотреть подробную информацию о нем и сохранить понравившиеся туры в избранное.

Сайт: https://kairkanova.github.io/tour-agency/

Тестовый аккаунт: `people@test.com` / `Travel2026`

## Страницы

- **Главная** (`index.html`) - подбор тура. Фильтры: страна, даты поездки, цена, рейтинг отеля, авиакомпания, прямые рейсы. Кнопка "Показать N туров" показывает сколько туров найдено, есть "Сбросить всё" и сортировка.
- **Страница тура** (`tour.html`) - фото, описание, программа по дням, отель, перелет, питание, страховка, отзывы, расчет стоимости. Тур можно добавить в избранное.
- **Избранное** (`favorites.html`) - сохраненные туры, переход на тур, удаление.
- **Регистрация и вход** (`register.html`, `login.html`).
- **Профиль** (`profile.html`) - личные данные, статистика, избранные туры, выход.
- **О нас** (`about.html`).

## Технологии

HTML, CSS, JavaScript (без фреймворков). Данные хранятся в JSON.

## Структура

```
css/style.css     стили
js/store.js       работа с данными (туры, пользователи, избранное)
js/ui.js          общие элементы (шапка, карточки, уведомления)
js/index.js       главная и фильтры
js/tour.js        страница тура
js/favorites.js   избранное
js/auth.js        вход и регистрация
js/profile.js     профиль
data/tours.json   туры
data/users.json   пользователи
images/           фотографии
```

## Данные

В `data/tours.json` лежат 12 туров. У каждого тура есть страна, город, даты, количество ночей, цена в долларах, данные отеля (звезды, рейтинг, отзывы), перелет (авиакомпания, прямой рейс, багаж), питание, страховка, описание, программа и фото.

В `data/users.json` лежат пользователи. Пароли хранятся в виде хеша SHA-256.

Так как у сайта нет своего сервера, новые пользователи и их избранное сохраняются в браузере (localStorage) в том же формате, что и `users.json`. В профиле свои данные можно посмотреть и скачать в виде JSON-файла.
